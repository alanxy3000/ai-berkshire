## 让市场恐惧的“SaaS 席位末日论”

如果说过去十年云计算的主旋律是“软件吞噬世界”，那么 2024-2026 年生成式 AI 与 Agentic AI（智能体）的狂飙突进，则给整个 SaaS 行业投下了一枚震撼弹：

```
市场对 SaaS 商业模式的核心恐慌逻辑链
┌─────────────────────────────────────────────────────────────┐
│ 1. AI 智能体 (Agents) 具备自主推理、拆解任务与代码执行能力  │
│                                                             │
│ 2. 企业内部 50% 的 IT 故障诊断与 60% 的日常客服工单被 AI 解决│
│                                                             │
│ 3. 跨国企业大幅裁减或冻结 IT 运维、客服与初级白领岗位       │
│                                                             │
│ 4. 依赖“按人头席位收费 (Per-Seat Pricing)”的 SaaS 收入断崖  │
│                                                             │
│ 5. 传统工作流软件被大模型 + 开源编排框架彻底“旁路化 (Bypass)”│
└─────────────────────────────────────────────────────────────┘
```

正是这种对底层商业根基的致命质疑，导致 ServiceNow 股价在 2026 年初遭遇了超过 50% 的断崖式回调，市场先生用极其冷酷的方式给所有传统应用软件贴上了“即将被 AI 颠覆”的标签。

然而，在 2026 年 7 月公布的最新 Q2 财报中，ServiceNow 却交出了一份极具反差的数据：
- **AI 相关年化合同价值（AI ACV）正式跨越 10 亿美元大关**；
- 订阅收入同比增长 **24.5%**（固定汇率下增长 23%），创下近几个季度以来的新高；
- 剩余履约义务（Total RPO）逆势扩张至 **290 亿美元**，客户续约率稳居 **98%+**。

在 Agentic AI 席卷一切的当下，ServiceNow 究竟是旧时代的恐龙，还是新时代不可或缺的控制台？AI 到底是在侵蚀它的基石，还是在给它的护城河注入水泥？

## 分业务拆解：赢家与输家在同一家公司体内分化

在讨论 AI 影响时，最忌讳给出非黑即白的简单结论。深入 ServiceNow 的业务内脏，我们会发现其不同业务线正面临截然不同的受力方向：

```
AI 对 ServiceNow 各大业务线的影响力图谱
┌─────────────────────────────────────────────────────────────┐
│ 1. IT 工作流 (IT Workflows) ——【确定性赢家 / 净受益者】     │
│    • Now Assist 自动生成故障根因分析、排障脚本与配置变更    │
│    • 客户从 Standard 升级至 Pro Plus，ACV 提价 30%-50%      │
│    • 驱动力：IT 架构越复杂，人类越依赖 AI 在 CMDB 上自动巡检 │
├─────────────────────────────────────────────────────────────┤
│ 2. 客户与员工工作流 (CSM / HR) ——【结构性分化 / 模式转型区】│
│    • 风险：一线客服与基础 HR 专员人头席位数增长面临自然停滞  │
│    • 对冲：通过 Assist Packs / 智能体调用量 (AI Units) 计费 │
│    • 结果：席位增速放缓，但单客户 ARPU 依靠高阶 AI 模块填补  │
├─────────────────────────────────────────────────────────────┤
│ 3. 创作者工作流 (Creator Workflows) ——【双刃剑 / 竞争白热化】│
│    • 优势：自然语言生成应用（Text-to-Workflow）极大降低门槛 │
│    • 威胁：微软 Power Platform、开源代码 Agent 带来外部竞争  │
└─────────────────────────────────────────────────────────────┘
```

### 1. IT 运维：AI 越强，系统越离不开统一中枢
在现代跨国企业中，混合云、微服务与容器化使得 IT 基础架构的复杂度呈指数级上升。当一个核心业务挂掉时，底层可能涉及上万个相互依赖的组件。
传统工程师排查需要几个小时；而 **Now Assist for ITOM** 能够在大模型理解拓扑关系后，数十秒内生成事故摘要并提出修复建议。这种能力直接推动了财富 500 强向 **Enterprise Pro Plus** 版本的全速迁移。

### 2. 客服与 HR：从“卖人头”转向“卖生产力”
如果一家银行原本购买了 5,000 个客服席位，未来因为引入 AI 智能体而缩减到 3,000 个席位，ServiceNow 的收入是否会下降？
答案是否定的。ServiceNow 正在推行 **混合计费模式**：企业虽然减少了部分基础席位，但必须为运行在平台上的每个 AI Agent 购买对应的“智能体授权（Assist Pack / Digital Worker License）”或支付更高的 Pro Plus 订阅费。企业的总 IT 开支不仅没有减少，反而因综合人力成本节约而更愿意向软件平台支付高溢价。

## 关键反问：大模型越来越聪明，ServiceNow 会沦为底层死管道吗？

许多技术乐观主义者会问这样一个尖锐的问题：
> “如果 OpenAI GPT-5、Claude 4.5 或开源 Agent 已经足够聪明，能够直接理解所有需求并生成代码，企业为什么还需要一个庞大笨重的 ServiceNow？”

要回答这个问题，必须理解企业级 AI 运转的**物理常识**：

```
大模型与企业执行系统分工 (The Brain vs The Muscle)
┌─────────────────────────────────────────────────────────────┐
│ 1. 大脑层 (Cognition & Intelligence)                        │
│    • 角色：OpenAI、Anthropic、DeepSeek、微软 Copilot         │
│    • 特长：自然语言理解、逻辑推理、多模态信息提炼           │
│    • 缺陷：没有企业内部状态、没有物理执行权限、存在幻觉风险 │
├─────────────────────────────────────────────────────────────┤
│ 2. 神经与动作执行中枢 (Action & Governance Engine)          │
│    • 角色：ServiceNow (Now Platform + CMDB)                 │
│    • 掌控：全球 8,000+ 巨头的组织架构、审批链、访问权限与 SLA│
│    • 职责：把大脑的“意图”转化为合规、可回滚、带审计的“动作” │
├─────────────────────────────────────────────────────────────┤
│ 3. 底层器官与数据孤岛 (Systems of Record)                   │
│    • 角色：SAP (ERP)、Salesforce (CRM)、Workday (HCM)       │
└─────────────────────────────────────────────────────────────┘
```

**大模型没有手脚，企业更不敢把核按钮交给没有审计护栏的大模型。**

试想一个真实的跨国企业场景：
AI Agent 通过分析发现欧洲机房的一组数据库存在安全漏洞，决定自动执行补丁更新。
如果直接让大模型调用底层脚本，可能会发生什么？
- 它不知道这组数据库正在承载欧洲区当天的季末财务结算；
- 它不知道按照欧盟 GDPR 和 SOC2 合规要求，任何生产变更必须由两位高级技术总监进行数字签名；
- 如果补丁失败，它不知道如何回滚到上一安全版本。

在企业世界里，**没有权限控制与状态记录的智能体就是最危险的病毒**。
AI Agent 要在企业内部真正落地，它的每一步动作必须通过 ServiceNow 的工作流引擎进行鉴权、路由、审批并在 CMDB 中留下不可篡改的审计日志。

ServiceNow 卖的从来不是“智能”，而是**企业级动作的合规性、确定性与可控性**。

## 巨头竞合格局：微软 Copilot 与 Salesforce Agentforce 的正面遭遇

在 AI 时代，ServiceNow 正在与软件行业的两位重量级选手展开激烈博弈：

```
三大巨头在 AI 时代的战略定位比对
┌─────────────┬──────────────────────────┬──────────────────────────┐
│ 公司        │ 核心 AI 武器             │ 优势与致命短板           │
├─────────────┼──────────────────────────┼──────────────────────────┤
│ ServiceNow  │ Now Assist &             │ • 优势：掌控底层 IT/CMDB │
│             │ Enterprise Pro Plus      │   与跨部门端到端动作编排 │
│             │ (AI ACV > 10 亿美元)     │ • 短板：缺乏桌面操作系统 │
│             │                          │   与前台办公入口         │
├─────────────┼──────────────────────────┼──────────────────────────┤
│ 微软 (MSFT) │ Copilot Studio &         │ • 优势：掌控 Windows/365 │
│             │ Azure AI                 │   桌面入口与海量办公文档 │
│             │                          │ • 短板：缺乏深度的企业 IT│
│             │                          │   资产依赖拓扑与工单治理 │
├─────────────┼──────────────────────────┼──────────────────────────┤
│ Salesforce  │ Agentforce               │ • 优势：强大的销售与营销 │
│ (CRM)       │ (自主客服与销售智能体)   │   前台客户数据           │
│             │                          │ • 短板：多起并购拼接架构 │
│             │                          │   难以穿透至 IT 与供应链 │
└─────────────┴──────────────────────────┴──────────────────────────┘
```

- **与微软的“亦敌亦友”**：微软是 ServiceNow 的战略盟友（ServiceNow 在 Azure 上深度部署，并与 Teams、Office 365 互联互通），同时双方在低代码与服务台上有局部竞争。但由于微软难以深入各行业极其定制化的 ITOM/ITAM 治理，双方目前更多维持着“微软提供前台入口、ServiceNow 提供后台编排”的共生关系。
- **与 Salesforce 的“前后对决”**：Salesforce 凭借 Agentforce 大力押注客服和销售自动化。但在跨部门复杂流程（如退货引发的退款审批、物流重新调度、库存核减与故障追责）上，Salesforce 往往需要调用 ServiceNow 的后台工作流来完成真正的交付。

## 5 个情景推演：从最佳预期到最坏打算

为了防范伪精确陷阱，我们不为各个发展路径分配主观概率加权，而是客观列出 5 种可能的情景及其触发条件：

```
ServiceNow AI 发展路径的 5 个情景推演

│ • 触发条件：Pro Plus 渗透率在 3 年内突破 40%，Now Assist 成为 │
│   全球 500 强调度所有第三方 Agent 的标准基础设施。           │
│ • 业绩结果：营收维持 22%-25% 高增，FCF 利润率扩张至 38%+。   │

│ • 业绩结果：净利润率短期承压 2-3 个百分点，股价面临中度折价。│
└─────────────────────────────────────────────────────────────┘
```

## 未来 1-2 年必须盯紧的监控信号清单

在跟踪 ServiceNow 的 AI 转型进展时，投资者应密切关注以下关键量化信号：

1. **AI ACV 的季度净增量**：是否能从当前的 10 亿美元在 2027 年底前迈向 20 亿美元；
2. **Pro Plus 在续约大单中的渗透比例**：每次披露中大客户升级 Pro Plus 的比率是否持续攀升；
3. **客户续约率与净留存率（NRR）**：续约率是否始终守住 **97%** 红线，NRR 是否维持在 **118%-122%** 区间；
4. **巨额技术并购动向**：关注其对 AI 智能体创业公司（如 Moveworks 等）的收购整合效果与商誉风险。

## 本篇要点回顾

1. **席位恐慌被过度放大**：市场担心的“AI 削减席位导致 SaaS 崩溃”忽略了企业级 AI 落地必须依赖权限与动作编排的物理现实。
2. **AI ACV 跨越 10 亿美元**：ServiceNow 成为全球软件业将生成式 AI 商业化兑现最快、体量最大的公司之一。
3. **大脑 vs 肌肉的分工**：大模型（OpenAI/微软）提供推理智能，ServiceNow 提供底层的企业权限治理、CMDB 关系图谱与动作执行。
4. **巨头竞合格局**：与微软在桌面入口与后台治理上形成共生互补，在复杂跨部门流程上相较 Salesforce 具备更深的中后台穿透力。
5. **5 种情景推演**：最核心的跟踪支点在于 Pro Plus 提价能否持续对冲席位增速的潜在放缓。
